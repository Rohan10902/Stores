# Store Data Assistant 7.2.0

Store Data Assistant is a local-first Windows desktop application for reviewing, validating, repairing, comparing, analysing, and creating structured store datasets.

## Production principles

- Source files remain unchanged unless the user explicitly exports a new file.
- Processing is local to the workstation.
- Store matching is identity/key based rather than row-position based.
- Repeated SIDs can be legitimate; Nielsen Store Code can be used as an additional identity key.
- Store-file creation uses the fixed 14-column output schema defined in `core/common.py`.
- Nielsen Store Code leading-zero changes are previewed before application and only all-digit identifiers are padded.
- Validation failures should be visible to the user instead of being silently discarded.

## Supported input

The application core supports CSV, TSV/text, Excel (`.xlsx`, `.xls`, `.xlsm`), JSON, and XML where the required pandas reader is available.

## Development

Requires Python 3.12.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python app.py
```

## Tests

```powershell
python -m unittest discover -s tests -p "test_*.py" -v
```

The production CI runs syntax checks, core import checks, regression tests, a packaged Windows build, and a launch smoke test before publishing the executable artifact.

## Windows build

The official artifact is generated by `.github/workflows/build-windows.yml`. Do not treat a successful PyInstaller command alone as a production pass: the workflow must also pass the packaged executable smoke test.

## Logs

Runtime diagnostics are written to the application's local data/log directory. If a packaged application fails unexpectedly, retain the latest log when reporting the problem.

## Release policy

`main` is the stable branch. Production changes should pass CI on a feature/release branch and be reviewed before merging. Release artifacts should be generated from the reviewed code rather than from an uncommitted local workspace.
