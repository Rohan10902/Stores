# 7.1.4 Startup Hotfix

The first 7.1.4 trial introduced new Create Store File QML.
This hotfix removes a startup-sensitive Shortcut binding and fixes nested Repeater row scoping in the spreadsheet grid.

For this hotfix, use the visible **Paste from Clipboard** button.
Ctrl+V will be reintroduced after the grid is confirmed to launch reliably on the packaged Windows Qt runtime.

No 7.1.3 comparison/repair/statistics backend behavior was removed.
