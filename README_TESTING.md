# Store Data Assistant 7.0 — Test Build

## Run from source
1. Install Python 3.11 or 3.12.
2. `pip install -r requirements.txt`
3. `python app.py`

## Test first
- Compare two small CSV/XLSX files.
- Click validation rows and verify field-by-field values.
- Test malformed quoted multiline CSV.
- Test Data Health + Statistics.
- Test Explore search and `SELECT * FROM data LIMIT 100`.

## Important
This is a 7.0 test build, not the final production release.
Source files are not overwritten by repair.
Keep a console build while testing.
